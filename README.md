# Proyecto TDD con Node.js
Proyecto desarrollado con Node.js y Vitest para practicar
el desarrollo guiado por pruebas (TDD).

## Funcionalidades
- Cálculo de la sucesión de Fibonacci.
- Validación de PIN de 4 o 6 dígitos.

## Tecnologías
- Node.js
- Vitest
- Chalk

## Metodología
Se utiliza el ciclo TDD:

1. RED: crear pruebas que fallen.
2. GREEN: implementar el código para superar las pruebas.
3. REFACTOR: mejorar el código manteniendo las pruebas superadas.
